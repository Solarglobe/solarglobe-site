Qu’est-ce que le calpinage solaire ?

Le calpinage consiste à définir la position précise de chaque panneau sur votre toit. C’est une étape technique essentielle qui détermine :

  • • L’orientation des panneaux (vers le sud, le sud-ouest ou le sud-est)
  • • L’espacement entre les modules pour éviter les ombrages
  • • L’organisation des panneaux sur la surface disponible

Un bon calpinage est crucial pour la production : il permet d’exploiter au maximum le potentiel de votre toiture tout en évitant les zones d’ombre ou les contraintes techniques qui réduiraient le rendement. Il s’appuie sur le dimensionnement et précède l’étude financière.
