03 · Le vrai risque

Le danger n’est pas le solaire. C’est un projet mal décidé.

Mauvaise puissance

Trop petit, le projet déçoit. Trop grand, il coûte trop cher.

Mauvais prix

Sans lecture claire, impossible de savoir si le devis est juste.

Mauvaise pose

Le meilleur matériel ne vaut rien si l’installation est mal exécutée.

Mauvais matériel

Une fiche technique incomprise peut cacher un choix peu adapté.

Mauvaise projection

Les économies doivent être réalistes, pas spectaculaires.

Mauvais suivi

Un projet solaire vit longtemps. Il doit rester lisible après la pose.
